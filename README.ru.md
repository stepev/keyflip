# KeyFlip

*[English](README.md) · **Русский***

Переключение раскладки клавиатуры **одиночным нажатием Ctrl** в Windows 11,
**перекодировка набранного не в той раскладке** по горячей клавише,
значок с **флагом текущего языка** в трее и автозапуск.

## Возможности

### 1. Одиночный Ctrl переключает раскладку

Глобальный низкоуровневый хук ловит нажатие и отпускание Ctrl. Переключение срабатывает,
только если между нажатием и отпусканием **не было** других клавиш, кликов мыши и других
модификаторов — то есть `Ctrl+C`, `Ctrl+Shift+Esc`, `Ctrl`+клик работают как обычно.
Если Ctrl держали дольше `maxhold` (400 мс), переключения не будет.
Синтетические нажатия игнорируются, поэтому конфликта с другими переключалками нет.

### 2. Перекодировка текста — по умолчанию `Ctrl+Shift+Backspace`

`ghbdtn` → `привет`, `Ghbdtn? vbh!` → `Привет, мир!`, и обратно.

* Если текст **выделен** — перекодируется выделение.
* Если выделения нет — перекодируется **последнее набранное слово**.
* Направление выбирается по преобладающему алфавиту, символы отображаются
  по физическим клавишам (`,` в английской раскладке — это `б` в русской).
* После перекодировки раскладка переключается под результат (`switchafterconvert`).

Сочетание меняется в меню трея → «Конвертация текста» → «Сочетание клавиш...»:
открывается окно, где нужно просто нажать желаемую комбинацию. Годится что угодно —
`Alt+F9`, `F12`, `Win+Q`, `Pause`, отдельная функциональная клавиша.
Комбинация регистрируется через `RegisterHotKey`, поэтому не доходит до активного
приложения (в частности, `Backspace` ничего не удаляет). Если сочетание уже занято
другой программой, приложение сообщит об этом.

**Как это работает.** Для последнего слова буфер обмена не используется вообще:
приложение ведёт собственный журнал набранных клавиш (низкоуровневый хук + `ToUnicodeEx`
с раскладкой активного окна), поэтому знает последнее слово и заменяет его напрямую —
`Backspace` по числу символов и ввод перекодированного текста через `SendInput`.
Это мгновенно и не трогает историю буфера обмена. Журнал сбрасывается всем, что уводит
курсор или меняет текст мимо клавиатуры: стрелки, Enter, Tab, Esc, Home/End, клик мыши,
смена активного окна, любые сочетания с Ctrl/Alt/Win (кроме самого сочетания перекодировки).

Порядок такой: если журнал не пуст — человек только что печатал, и слово заменяется сразу,
без обращения к буферу обмена; если журнал пуст — пробуем выделение.

Для выделенного текста без буфера обмена не обойтись — прочитать выделение в чужом
приложении иначе нельзя. Приложение запоминает текущий текст буфера, посылает `Ctrl+C`,
ждёт изменения `GetClipboardSequenceNumber` (до 250 мс), перекодирует текст и **вводит
его напрямую**, заменяя выделение, после чего возвращает прежнее содержимое буфера.
Свои служебные записи в буфер приложение помечает форматами
`CanIncludeInClipboardHistory`/`CanUploadToCloudClipboard`, поэтому в истории `Win+V`
и в облачном буфере они не появляются.

### 3. Значок в трее

* Флаг текущего языка ввода активного окна, обновляется ~3 раза в секунду.
* Перечёркнутый серый флаг — переключение выключено.
* Двойной клик — включить/выключить, правый клик — меню.
* Меню показывает действия («Включить»/«Выключить») и состояние автозапуска.
* Флаги нарисованы кодом примерно для 60 стран; если флага для языка нет,
  показывается код языка (`RU`, `EN`) — этот режим можно выбрать и вручную.

### 4. Язык интерфейса

Меню → «Язык»: «Как в Windows» (по умолчанию), «Русский», «English».
Выбор применяется сразу, без перезапуска. Пункт «О программе» показывает версию,
краткую справку по клавишам и ссылку на исходники.

## Установка

Штатная установка «для текущего пользователя», без прав администратора — запустите
**`install.cmd`** (двойным кликом или из терминала). Для установки без окна
подтверждения: `install.cmd /s`.

Сам скрипт намеренно написан только латиницей и ничего не печатает по-русски:
кодовая страница консоли в Windows непредсказуема. Все понятные сообщения
(в том числе об ошибке) показывает уже приложение — обычным окном.

Установщик при необходимости соберёт приложение и затем:

* скопирует exe в `%LOCALAPPDATA%\Programs\KeyFlip\`;
* создаст ярлык в меню «Пуск»;
* зарегистрирует приложение в **Параметры → Приложения → Установленные приложения**
  (с кнопкой «Удалить»);
* включит автозапуск при входе в Windows;
* запустит установленную копию.

После установки исходную папку `bin` можно удалить.

### Удаление

Через **Параметры → Приложения → Установленные приложения → KeyFlip → Удалить**
или запуском `uninstall.cmd` (`/s` — без вопросов). Удаляются папка установки, ярлык, автозапуск и запись
в списке приложений; про настройки программа спросит отдельно.

### Аргументы командной строки

| Аргумент            | Действие                                           |
|---------------------|----------------------------------------------------|
| `--install`         | установить (добавьте `--silent` — без окон)        |
| `--uninstall`       | удалить (`--silent` — без вопросов)                |
| `--autostart:on`    | включить автозапуск и выйти                        |
| `--autostart:off`   | выключить автозапуск и выйти                       |

## Сборка

Нужен только Windows — компилятор C# входит в состав системы (.NET Framework 4.x),
устанавливать .NET SDK не требуется.

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `bin\KeyFlip.exe` — один файл ~60 КБ без зависимостей.
Иконка приложения генерируется скриптом `tools\make-icon.ps1` в `assets\app.ico`
(сборка вызовет его сама, если файла нет).

## Настройки

Всё настраивается из меню в трее. Те же значения хранятся в файле
`%LOCALAPPDATA%\KeyFlip\config.ini` — его можно править вручную,
изменения подхватываются при следующем запуске.

```ini
enabled=1                      # 1/0 — работает ли переключение по Ctrl
method=post                    # post | winspace | altshift | ctrlshift
trigger=both                   # both | left | right — какой Ctrl считать триггером
maxhold=400                    # макс. время удержания Ctrl в мс (0 = без ограничения)
icon=flag                      # flag | code
autostart=1
hotkey=Ctrl+Shift+Backspace    # перекодировка текста; пусто — выключено
switchafterconvert=1           # переключать раскладку под результат перекодировки
log=0                          # 1 — писать log.txt рядом с настройками (диагностика)
```

### Способы переключения раскладки

| Значение    | Что делает                                                                  |
|-------------|------------------------------------------------------------------------------|
| `post`      | (по умолчанию) `WM_INPUTLANGCHANGEREQUEST` активному окну — мгновенно          |
| `winspace`  | эмулирует `Win + Пробел` — работает везде, где работает штатное переключение   |
| `altshift`  | эмулирует `Alt + Shift`                                                        |
| `ctrlshift` | эмулирует `Ctrl + Shift`                                                       |

Если в каком-то приложении (обычно Store/UWP) `post` не срабатывает — выберите `Win + Пробел`.

## Ограничения

* Окна, запущенные **от имени администратора**, не отдают события обычному хуку, поэтому
  внутри них KeyFlip не работает. Запускать пользовательскую копию с повышением прав **нельзя**:
  в `%LOCALAPPDATA%\Programs\KeyFlip` может писать любой непривилегированный процесс от вашего
  имени, то есть подменённый exe затем стартовал бы с правами администратора. Если такая
  поддержка действительно нужна, положите exe туда, куда обычный пользователь писать не может
  (например, `%ProgramFiles%\KeyFlip` — эта папка создаётся с правами администратора),
  и запускайте с повышением именно её.
* На экране блокировки, в UAC-запросе и на защищённом рабочем столе хук не работает —
  ограничение Windows.
* Перекодировка выделенного текста использует `Ctrl+C`, поэтому не сработает там, где
  копирование недоступно. Прежний текст буфера обмена восстанавливается, но нетекстовое
  содержимое (картинка, файлы) будет потеряно — его затирает само копирование.
* Перекодировка последнего слова работает по журналу набранного: если слово было введено
  не с клавиатуры (вставлено, набрано до запуска программы, перед ним кликнули мышью),
  журнал пуст и перекодировать нечего — выделите текст.
* Раскладок должно быть минимум две.

## Структура

```
src/Program.cs    — хуки, одиночный Ctrl, переключение раскладки, горячая клавиша,
                    журнал набранного, перекодировка, трей, конфиг, лог
src/Translit.cs   — таблица соответствия ЙЦУКЕН ↔ QWERTY, разбор последнего слова
src/TypedJournal.cs — журнал набранных клавиш (что считается словом, когда сбрасывать)
src/Hotkey.cs     — разбор сочетаний клавиш и окно их настройки
src/Installer.cs  — установка/удаление, ярлык, запись в списке приложений
src/Flags.cs      — отрисовка флагов для значка в трее
tools/make-icon.ps1 — генерация assets/app.ico
build.ps1         — сборка
install.cmd / uninstall.cmd — установка и удаление
```
